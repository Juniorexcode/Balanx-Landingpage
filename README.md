Welcome to **Balanx Landing Page**, a highly interactive, space-themed FinTech dashboard and landing experience built with modern web technologies. This project focuses on high-performance animations, fluid glassmorphism, and a deeply engaging user experience.

## ✨ Features
- **Immersive 3D Space Theme:** Animated glowing earth, stars, rockets, and dynamic space elements that react to scroll.
- **Scroll-Driven Storytelling:** Utilizes `framer-motion` for complex scroll animations, sticky layouts, and smooth transitions as the user navigates down the page.
- **Dynamic Data Visualization:** Animated real-time SVG charts with neon glow effects.
- **Glassmorphism UI:** Sophisticated frosted glass widgets with deep blurs and dark translucent backgrounds.
- **Interactive Pricing Tickets:** 3D animated pricing cards with hover transforms and detailed CSS styling.
- **Optimized Performance:** Fully built on top of React, Vite, and Tailwind CSS.

## 🛠️ Technology Stack
- **Frontend Framework:** React (with TypeScript)
- **Styling:** Tailwind CSS + Vanilla CSS (for complex 3D tickets & mix-blend modes)
- **Animations:** Framer Motion & React-Scroll
- **Build Tool:** Vite

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Juniorexcode/Balanx-Landingpage.git
```

2. Navigate into the directory:
```bash
cd BalanX-Dashboard
```

3. Install dependencies:
```bash
npm install
```

4. Run the development server:
```bash
npm run dev
```
